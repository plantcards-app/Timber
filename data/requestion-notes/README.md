things later."

This folder is that. One file per plant with an open question: what the card says now, what is doubtful or missing
and why, a paste-ready question for your research tool, and what happens in the repo when the answer comes back.
Every doubt here is [Unverified] unless the note says otherwise; the fact checks behind them worked from search
snippets because the proxy blocks page reads, so a page you open yourself outranks anything written here.

When you have an answer: paste it (a corrected JSON, or just the field and the value) and it goes on the card
with `compare-double --apply` / `--set`, the batch README records it, and the note here is deleted. A note is
removed only when its question is answered or you say drop it.
